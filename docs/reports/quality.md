## 3. Как воспроизвести

```bash
# окружение: Python 3.12 + Node 22, зависимости из lock-файлов с хэшами
python3.12 -m venv .venv && . .venv/bin/activate
pip install --require-hashes -r requirements-dev.lock
cd frontend && npm ci && npm run build && cd ..

# регресс без сети и без затрат (fixtures)
make check                                    # ruff, pytest+покрытие, трассировка, OpenAPI, схемы навыков, фронтенд
LLM_PROVIDERS=fixtures DATA_DIR=$(mktemp -d) PYTHONPATH=src python -m uvicorn app.main:app --port 8765 &
python scripts/autorun.py                     # 5 кейсов, exit-код 0 только при полном PASS
python scripts/e2e_regression.py --base http://127.0.0.1:8765 --all-cases
BASE_URL=http://127.0.0.1:8765 NODE_PATH=$(npm root -g) node e2e/ui_roles.spec.cjs

# живой замер на стенде (та же команда, что дала цифры раздела 1)
# POST https://…/api/v1/programs?mode=auto {"request": <кейс 3 из testset/cases.json>, "attachments": [...], "wait": true}
```

- Раздел 1 — единичный полный прогон на живой модели 21.10; повторяемость подтверждается ежедневными автопрогонами организаторов и разделом 2 на фикстурах.
