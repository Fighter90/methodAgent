# История изменений

Версии поставки на стенд команды и главное в каждой. Даты по МСК. Подробности — в истории коммитов.

## v28 — 19.10.2026

- Поиск по базе знаний расшифровывает сокращения в запросе: «педагог ДО» находит профстандарт «Педагог дополнительного образования».

## v27 — 19.10.2026

- Оборванный ответ модели в навыке content больше не превращает весь модуль в шаблон: берётся целая часть ответа, недостающее добирается по шаблону, отказ виден в `step_errors`. Причина: в живом прогоне кейса 3 ответ по итоговому модулю оборвался на 3,9 тыс. символов.

## v26 — 19.10.2026

- Поиск по базе знаний: выдача документов организации и выжимок норм сливается по местам (reciprocal rank fusion), а не по сырым оценкам разных шкал, поэтому найденное по смыслу не уступает совпадению слов в выжимках норм.

## v25 — 19.10.2026

Закрыты оставшиеся частичные пункты ТЗ по доступу и навыкам.

- Вход: токен доступа на 30 минут и токен обновления на 30 дней (`POST /api/v1/auth/refresh`); интерфейс продлевает вход сам.
- Администратор выдаёт и отзывает токены API (`/api/v1/admin/api-tokens`, вкладка «Токены API»); в базе хранится только хэш.
- Не больше 30 новых программ в час на пользователя и отдельный лимит для роли api, оба настраиваются.
- Настройки `SANDBOX_TIMEOUT_S` и `SANDBOX_MEMORY_MB` для песочницы.
- У каждого навыка есть `schema_out.json`, сгенерированный из модели ответа; `scripts/export_skill_schemas.py --check` сверяет их с кодом.
- Поиск по базе знаний: пока часть документов без векторов, совпадение слов не вытесняет найденное по смыслу.
- Регресс: pytest 299 тестов, покрытие 92 %; API по всем ролям и 5 кейсам 1381/1381; интерфейс 90/90. Сверка с ТЗ: 324 выполнено, 51 частично, 6 не выполнено.

## v24 — 19.10.2026

Полный регресс и закрытие инструментов разработки по ТЗ 4.11.

- Интерфейс: ESLint (правила TypeScript и хуков React, без предупреждений) и юнит-тесты vitest для клиента API (`npm run lint`, `npm run test`, `npm run check`).

- `Makefile`: `make check` повторяет CI, `make e2e` запускает сквозной регресс на поднятом сервисе.
- Регресс на финальном коде: pytest 290 тестов, покрытие 91 %; API по всем ролям и 5 кейсам 1381/1381; интерфейс по ролям 89/89; smoke и автопрогон зелёные. Сверка с ТЗ: 318 выполнено, 57 частично, 6 не выполнено (только метрики пилота и замеры с методистом).

## v21 — 19.10.2026

Доработки по результатам автоматической проверки жюри.

- Только Cloud.ru: пакет `openai` убран из зависимостей, обращение к Cloud.ru Evolution Foundation Models идёт через собственный клиент на httpx (`src/app/llm/gateway.py`). Переменных `OPENAI_*` в коде и конфигурации нет: ключ и адрес задаются `LLM_API_KEY` и `LLM_BASE_URL`, на ВМ их заполняет `scripts/deploy_vm.sh`.
- Устойчивость конвейера: параллельная генерация модулей без общих изменяемых данных (свой результат и `CallStats` у каждой задачи, слияние по порядку модулей, `CallStats` под замком); узкие перехваты исключений в навыках (`LLMUnavailable` и ошибки разбора ответа) и структурный журнал отказов `step_errors`; таймауты и повторы у эмбеддингов и `ping`; `needs_answers` и `POST /programs/{id}/answers?mode=auto|wait=true` для API-клиента; гарантия слайдов хотя бы одного модуля без модели. Стратегия — `docs/llm.md`, раздел «Таймауты, повторы и отказы».
- Воспроизводимость: базовые образы закреплены по digest, зависимости ставятся из `requirements.lock` с хешами, добавлены `.python-version`, `.nvmrc`, `scripts/run_local.sh`, `scripts/smoke.sh`, пошаговый запуск без Docker и без ключа LLM. CI в `.gitea/workflows/ci.yml`, порог покрытия 70 % по ТЗ.
- Сквозной регресс: `scripts/e2e_regression.py` (1381 проверка по всем ролям и форматам) и `e2e/ui_roles.spec.cjs` (интерфейс всех ролей). Исправлены 5 найденных ошибок, в том числе доступ API-клиента к чужой программе через адаптацию и чтение разделов неназначенным экспертом.
- Сверка с ТЗ по каждому пункту: `docs/tz-compliance.md`. Исправлены пересчёт проверок после выбора варианта графика в auto, шапка УТП и кадровое обеспечение в DOCX, ограничение попыток входа, уведомление эксперта о возврате модуля.
- Эффект программы: блок `effect` в ответе автопрогона и карточка «Эффект» на странице программы (часы методиста вручную и на вычитку, экономия, цена часа экономии).
- Тип программы определяется по сокращениям «ДООП», «ДПП», «ПК», «ПП» и по детской аудитории.
- Реестр профстандартов: 47 записей, добавлены маркетолог, бухгалтер, HR, экономист, дизайнер, журналист, редактор, документационное обеспечение, врач, медсестра.
- Состав команды и роли в README.
- Векторы базы знаний организации хранятся float32-матрицами в `data/kb/vectors/` с кэшем в памяти, а не в `index.json`: поиск не перечитывает сотни мегабайт на каждый запрос, старый индекс переносится автоматически. `POST /api/v1/kb/reindex` догоняет эмбеддингами документы без векторов.
- Главная: карточки с цифрами одной высоты.
