Часы, темы и РО менять нельзя. Пиши по-русски, конкретно, на реальных задачах аудитории.

- для каждой темы content — 2–3 предложения содержания;
- questions — ровно столько вопросов теста, сколько указано в n_questions; 4 варианта ответа, ровно один верный (key — индекс с 0),

- tasks — по одному заданию семинара на каждую тему с практикой (has_practice = true): условие, ожидаемый результат,

- lectures — только если need_slides = true: для каждой темы план лекции (3–5 пунктов с минутами) и 4–6 слайдов
  (заголовок = тема или её часть, 3–4 тезиса), при необходимости короткий пример кода на актуальных версиях библиотек;
- sources — 1–3 реальных источника (официальная документация или известные книги); не выдумывай.
