# Судья смысловых правил

Префикс требований: `SPEC-JUDGE`. Код: `src/app/validation/judge.py`. Подробности — [docs/validation.md](../docs/validation.md#судья-judgepy). Тесты: `tests/test_spec_judge.py`.

## Назначение

Модель рассуждений уточняет четыре смысловых правила (V-21, V-22, V-26, V-27), которые код оценивает эвристиками (FR-33). Судья может перевести правило в «предупреждение» с замечаниями, но не снимает замечаний кода; правила не блокирующие.

## Требования

| ID | Требование | Источник | Тест |
|---|---|---|---|
| SPEC-JUDGE-01 | IF модель не настроена или судья отключён настройкой `llm_judge_enabled`, THEN THE SYSTEM SHALL не вызывать судью и вернуть пустой журнал. | FR-33 | `test_spec_judge.py::test_judge_skipped_when_disabled` |
| SPEC-JUDGE-02 | WHEN судья включён, THE SYSTEM SHALL вызвать модель с навыком и ролью `judge`, температурой 0, лимитом 4096 токенов, схемой `JudgeOut` и текстами четырёх правил. | FR-33, NFR-09 | `test_spec_judge.py::test_judge_call_parameters` |
| SPEC-JUDGE-03 | THE SYSTEM SHALL передавать судье только сжатое представление программы: название, тип, объём, аудиторию, цель, РО, модули с темами, аннотации до 200 символов и последние 3 заметки агента до 160 символов. | код | `test_spec_judge.py::test_view_is_compact` |
| SPEC-JUDGE-04 | WHEN судья ответил, THE SYSTEM SHALL заменить `kit.judge` вердиктами `warn` известных правил с непустыми замечаниями (не больше 3, без пробелов по краям) и вернуть журнал «<правило>: <первое замечание>». | FR-33 | `test_spec_judge.py::test_only_warn_with_messages_kept` |
| SPEC-JUDGE-05 | IF вызов судьи завершился ошибкой, THEN THE SYSTEM SHALL вернуть пустой журнал без исключения, сохранив оценки кода. | FR-33, NFR-08 | `test_spec_judge.py::test_judge_failure_keeps_code_results` |
| SPEC-JUDGE-06 | WHEN замечания судьи сводятся в отчёт, THE SYSTEM SHALL перевести `pass` в `warn`, не менять `fail`, добавить замечания с префиксом «Судья:» к замечаниям кода и не трогать правила без замечаний судьи. | FR-33 | `test_spec_judge.py::test_merge_adds_judge_messages` |

## Вне области

Качество суждений модели, промпт судьи, условие запуска при исчерпанном суточном лимите (проверяется в `generate_kit`), эвристики правил кодом. При ошибке судьи прежнее содержимое `kit.judge` не очищается — поведение не специфицировано.
