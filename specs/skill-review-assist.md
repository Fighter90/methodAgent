# Навык review_assist

Префикс требований: `SPEC-REVIEW`. Код: `src/app/skills/review_assist/run.py`. Подробности — [docs/skills.md](../docs/skills.md#review_assist). Тесты: `tests/test_spec_review_assist.py`.

## Назначение

Предложение правки по замечанию эксперта в пределах его модуля: находит текст фрагмента, к которому оставлено замечание, просит модель сформулировать правку и перечисляет элементы, которые пересоберутся по графу связей (FR-41, FR-47, FR-48). Часы и РО при этом не меняются.

## Требования

| ID | Требование | Источник | Тест |
|---|---|---|---|
| SPEC-REVIEW-01 | THE SYSTEM SHALL возвращать текст фрагмента по идентификатору узла: задание (с критериями), критерий `task#cN`, вопрос (с вариантами), лекция (с планом), пункт плана `lec#pN` (минуты и текст), слайд (с тезисами); для неизвестного узла — пустую строку; номер больше числа элементов даёт текст элемента целиком. | FR-47 | `test_spec_review_assist.py::test_fragment_of` |
| SPEC-REVIEW-02 | IF номер критерия или пункта плана вне диапазона 1…N (в том числе 0), THEN THE SYSTEM SHALL вернуть текст элемента целиком. | FR-47 | `test_spec_review_assist.py::test_fragment_of_zero_index_is_whole_element` (xfail) |
| SPEC-REVIEW-03 | WHEN модель доступна и фрагмент найден, THE SYSTEM SHALL вызвать навык `review_assist` со схемой `Proposal`, передав фрагмент и замечание, и вернуть поле `proposal`. | FR-41 | `test_spec_review_assist.py::test_propose_uses_model` |
| SPEC-REVIEW-04 | IF модель недоступна, ответила ошибкой или фрагмент не найден, THEN THE SYSTEM SHALL вернуть шаблон «Учесть замечание эксперта: «…». Правка затронет только этот элемент модуля; часы и РО не меняются.» без вызова модели для ненайденного фрагмента. | FR-41, FR-48 | `test_spec_review_assist.py::test_propose_fallback` |
| SPEC-REVIEW-05 | WHEN запрошено полное предложение, THE SYSTEM SHALL вернуть текст предложения и список `rebuild` потомков узла по графу связей; IF узел пуст или граф не находит узел, THEN THE SYSTEM SHALL вернуть пустой список затрагиваемых элементов. | FR-41 | `test_spec_review_assist.py::test_propose_full_affected` |

## Известные расхождения

Нет. Расхождение по SPEC-REVIEW-02 (номер 0 давал последний элемент) исправлено в v20: проверка номера теперь `1 <= n <= len(...)`.

## Вне области

Применение правки (`new_text`) и подтверждение экспертом (FR-48) — в `workflow.py`; содержание промпта `SKILL.md`; качество формулировок модели.
