# Конвейер агента

Префикс требований: `SPEC-FLOW`. Код: `src/app/agent/workflow.py`, `src/app/agent/sections.py`, `src/app/agent/extras.py`. Подробности — [docs/agent-workflow.md](../docs/agent-workflow.md).

## Назначение

Оркестратор ведёт документ программы `ProgramDoc` по конечному автомату `draft → questions → skeleton → skeleton_approved → generating → kit_ready → on_review → on_approval → approved` (возврат — `returned`, сбой автопрогона — `failed`), вызывает навыки, солверы, правила, автоисправление и судью, выполняет точечные правки, вычитку и согласование. `sections.py` собирает тексты разделов шаблона АЦР, `extras.py` — сценарии сверх основного потока (смена шаблона, адаптация, актуализация, версии, песочница, нормативная база, подсказка экспертов).
