# Интерфейс

Префикс требований: `SPEC-UI`. Код: `frontend/src` (`App.tsx`, `api.ts`, `pages/*.tsx`, `components/ui.tsx`). Подробности — [docs/frontend.md](../docs/frontend.md), [docs/roles-and-access.md](../docs/roles-and-access.md) (раздел 9).

## Назначение

Одностраничное приложение на React: маршруты, оболочка с меню по ролям, переключатель ролей и уведомления, шаговый мастер программы, экраны вычитки, базы знаний, администрирования и личного кабинета. Клиент API передаёт токен в `X-MA-Token`, повторяет безопасные запросы при сбоях сети и показывает недоступность сервера. Интерфейс только скрывает разделы — права проверяет сервер.

Автотестов интерфейса (Playwright и т. п.) в репозитории нет: требования проверяются вручную по сценарию всех ролей в Chromium (см. `tz-compliance.md`). Серверная часть контрактов, на которые опирается интерфейс, покрыта требованиями [auth-and-roles.md](auth-and-roles.md) и [api.md](api.md).

## Вне области

- Серверная проверка прав (интерфейс только скрывает разделы).
- Мобильные приложения и офлайн-режим с локальным хранением программ.
- Автотесты интерфейса в браузере (не настроены).
