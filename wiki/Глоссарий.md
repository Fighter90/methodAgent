# Глоссарий

Термины и сокращения, которые встречаются в МетодАгенте и в этой вики. Внутри групп термины расположены по алфавиту.

## Типы программ и документы

| Термин | Расшифровка и смысл |
|---|---|
| **ДООП** | Дополнительная общеобразовательная общеразвивающая программа: программа для детей и взрослых без требований к квалификации. Порядок — приказ Минпросвещения № 629. В МетодАгенте: тип `doop`, без профстандарта, выдаётся сертификат |
| **ДПО** | Дополнительное профессиональное образование: повышение квалификации и профессиональная переподготовка |
| **ДПП** | Дополнительная профессиональная программа. Порядок — приказ Минобрнауки от 24.03.2025 № 266 (заменил № 499) |
| **ДПП ПК** | Дополнительная профессиональная программа повышения квалификации. Тип `dpp_pk`, опирается на профстандарт и трудовые функции, выдаётся удостоверение о повышении квалификации |
| **ДПП ПП** | Дополнительная профессиональная программа профессиональной переподготовки. Код уровня `dpp_pp` встречается в разметке реестра; агент такие программы пока не собирает |
| **Проект приказа** | DOCX приказа об утверждении программы с пустыми реквизитами |
| **Стажировка** | Форма ДПП ПК, в которой вся работа самостоятельная под руководством наставника. Тип `dpp_pk_internship`: ЛК, ПР и ЛБ равны нулю, все часы модулей — СРС, текущий контроль — собеседование |
| **Шаблон АЦР** | Структура разделов программы, принятая в Академии цифрового развития: своя для ДПП ПК и для ДООП |

## Нормативные документы

| Термин | Расшифровка и смысл |
|---|---|
| **ГИА** | Государственная итоговая аттестация (ГИА-9, ГИА-11 в школе; ГИА СПО и ВО). Есть в выжимках для основных программ; в ДПП и ДООП используется итоговая аттестация (ИА) |
| **ЕКС** | Единый квалификационный справочник должностей |
| **Выжимка** | Файл `registry/norms/*.md` с кратким изложением акта и номерами пунктов. Фрагменты выжимок идут в промпты навыков |
| **НПА** | Нормативный правовой акт: закон, постановление, приказ, письмо |
| **ОТФ** | Обобщённая трудовая функция профстандарта; объединяет несколько ТФ |
| **ПС** | Профессиональный стандарт Минтруда. Для ДПП ПС подбирается из реестра; коды ТФ берутся только оттуда |
| **Реестр** | Проверенный список в `registry/*.json`: НПА, ПС, ФГОС, литература, версии инструментов. У каждой записи есть дата проверки и ссылка |
| **ТФ** | Трудовая функция профстандарта с кодом (например, A/01.5). Компетенции ДПП связываются с ТФ |
| **ФГОС** | Федеральный государственный образовательный стандарт (НОО, ООО, СОО, СПО, ВО) |
| **ФОП** | Федеральная образовательная программа (НОО, ООО, СОО) |
| **ФРДО** | Федеральный реестр документов об образовании (ФИС ФРДО) |
| **273-ФЗ** | Федеральный закон «Об образовании в Российской Федерации»; входит в нормативную базу любой программы |

## Структура программы

| Термин | Расшифровка и смысл |
|---|---|
| **З/У/Н** | Знания, умения, навыки. В ДПП индикаторы компетенции — «знать / уметь / владеть», в ДООП — блоки «Знания / Умения / Навыки» |
| **ИА** | Итоговая аттестация: зачёт, защита проекта, экзамен, отчёт о стажировке и т. п. |
| **Индикатор** | Часть компетенции вида «знать», «уметь» или «владеть»; содержит РО |
| **Каркас** | Первый результат агента: цель, компетенции, РО, ПС и ТФ, модули и темы с часами, ИА, нормативная база, календарный график. Пока каркас не утверждён, содержание не генерируется |
| **Компетенция** | Профессиональная (ПК, для ДПП) или общая (К, для ДООП) способность, которую формирует программа |
| **Комплект** | Всё, что агент собирает после утверждения каркаса: рабочие программы модулей, тесты, задания, лекции и слайды, материалы ИА, разделы шаблона, источники |
| **КУГ** | Календарный учебный график |
| **Модуль** | Крупная часть программы с темами, часами по видам работы и формой контроля |
| **Оценочное средство** | Способ проверки РО: тест модуля, семинар (задание), собеседование, итоговый тест, ИА |
| **РО** | Результат обучения: что слушатель знает, умеет или чем владеет, сформулированный проверяемым действием (V-22). Каждый РО должен быть раскрыт в теме (V-12) и проверяться минимум двумя средствами (V-13) |
| **Рабочая программа модуля** | Аннотация модуля, содержание тем и контрольные вопросы |
| **Тема** | Часть модуля с часами по видам работы, РО и пререквизитами |
| **УП** | Учебный план: модули с часами по видам работы |
| **УТП** | Учебно-тематический план: учебный план с темами |

## Часы

| Термин | Расшифровка и смысл |
|---|---|
| **Ак. ч** | Академический час (45 минут); длительность лекции по умолчанию — ЛК × 45 минут |
| **Контактная работа** | ЛК + ПР + ЛБ: часы, когда преподаватель работает со слушателями |
| **ЛБ** | Лабораторные занятия |
| **ЛК** | Лекции |
| **Метод наибольших остатков** | Способ делить целое число часов по весам так, чтобы суммы сходились точно. См. [Часы и календарь](Часы-и-календарь) |
| **ПР** | Практические занятия |
| **СРС** | Самостоятельная работа слушателя |
| **Солвер** | Код, который детерминированно раскладывает часы и строит календарь |

## Формы обучения

| Термин | Расшифровка и смысл |
|---|---|
| **ДОТ** | Дистанционные образовательные технологии |
| **ЭО** | Электронное обучение. Правила ЭО и ДОТ — постановление Правительства № 1678 |
| **Очно-заочная форма** | Сочетание аудиторных занятий и самостоятельной работы; значение по умолчанию во встроенных умолчаниях |

## Работа агента

| Термин | Расшифровка и смысл |
|---|---|
| **Автопрогон** | Создание программы одним запросом `POST /programs?mode=auto` без вопросов |
| **Блокирующая проверка** | Одна из 10 групп правил; пока хотя бы одна не пройдена, нельзя назначить экспертов и отправить программу на утверждение |
| **Допущение** | Значение, которое агент принял сам («На ваше усмотрение» или режим auto); помечается «принято агентом» |
| **Индекс готовности** | `round(100 × (пройденные блокирующие + принятые модули) / (10 + число модулей))`; утверждение возможно при 100 % |
| **Матрица покрытия** | Таблица «РО × средство оценивания» в отчёте |
| **Навык** | Каталог `src/app/skills/<имя>/` с `SKILL.md`, схемой и кодом: отдельный шаг работы агента |
| **Песочница** | Изолированный запуск примеров кода из лекций без сети, с лимитами времени и памяти |
| **Пункт «!»** | Предупреждение в отчёте, по которому методист принимает решение: принять предложение агента или оставить как есть |
| **Референс** | Приложенный файл программы-образца; из него берётся только структура |
| **Резервная генерация** | Детерминированная сборка без модели (библиотека типовых каркасов, шаблонное содержание) |
| **Судья** | Рассуждающая модель `GigaChat3.5-432B-A28B-Reasoning`, которая уточняет смысловые правила V-21, V-22, V-26, V-27 |
| **Точечная правка** | Изменение одного элемента комплекта, при котором пересобираются только его потомки в графе |
| **V-правила** | Правила автопроверки V-01…V-27. См. [Автопроверка](Автопроверка) |
| **8-граммы** | Последовательности из 8 слов; по ним считается совпадение с референсом (V-17, порог 5 %) |

## Технические термины

| Термин | Расшифровка и смысл |
|---|---|
| **GIFT** | Текстовый формат тестов Moodle |
| **JSON 4.8** | Машиночитаемая выгрузка комплекта по схеме подраздела 4.8 ТЗ |
| **JWT** | Токен входа; содержит id пользователя, активную роль и срок жизни |
| **LMS** | Система управления обучением (например, Moodle) |
| **SDD** | Разработка по спецификациям: спецификация → тесты → код. См. [Разработка](Разработка) |
| **X-MA-Token** | Заголовок, в котором интерфейс передаёт токен приложения; нужен, потому что прокси хаба перехватывает `Authorization` |
| **Хаб** | Платформа хакатона, через которую открыт демо-стенд; у неё свой вход |
