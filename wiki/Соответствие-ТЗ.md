## Как проверено

- **Автотесты** (`pytest -q`): права по таблице 19, жизненный цикл, JSON 4.8, правки с откатом, вычитка по элементам, решения по пунктам «!», часы тем, хронометраж, разбор PDF, солвер часов (hypothesis). После сверки к ним добавились тесты под требования спецификаций (см. [Разработка](Разработка)).
- **Автопрогон пяти открытых кейсов** на детерминированных ответах навыков: все со статусом `done`, блокирующие проверки 10/10, чек-листы кейсов пройдены.
- **Сборка на нормативной базе**: по каждому кейсу проверено, какие акты, ПС и выдержки взял агент (см. [Нормативная база](Нормативная-база)).
- **Сценарий всех ролей в браузере**: запрос → каркас → правка часов темы → проверка → комплект → точечная правка → назначение экспертов по подсказке → вычитка с оценкой → отправка → утверждение → профиль администратора. Ошибок консоли и ответов 4xx/5xx нет.
- **Проверка на сервере**: найденные замечания (вычитка неназначенным экспертом, HTML вместо JSON для неизвестных путей API, нет списка непроверенных элементов) исправлены и перепроверены.
